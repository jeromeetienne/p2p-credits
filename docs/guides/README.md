# The Guides

One document per task, for a reader who already knows the vocabulary and has come here to perform that one task. Each guide is complete on its own: a reader who opens one guide and reads nothing else can perform the task.

- [Price a new task type](price_a_new_task_type.md) — measure a reference cost, and add the task type.
- [Choose a settlement policy](choose_a_settlement_policy.md) — immediate credit, provisional credit, or delayed settlement.
- [Choose a penalty](choose_a_penalty.md) — the five penalties, and what each one costs an honest worker.
- [Compare results that are not deterministic](compare_non_deterministic_results.md) — the four comparison strategies, and when each one holds.
- [Set the cost of an identity](set_the_cost_of_an_identity.md) — what stops a Sybil attacker from paying for an identity.

A guide names the exact parameter and the exact exported name, and links to [the reference](../reference/) for the full signature. The reason behind a choice is in [the explanation](../explanation/).

The index of every document is [`docs/README.md`](../README.md).
